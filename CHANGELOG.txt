Change Log
======================

0.3.19 (21/04/2026)
---------------------
Hardening release focused on dead-code removal, documentation accuracy,
and closing the last class of silent-failure bugs surfaced in a deep
review. Includes several behaviour changes — see "Breaking" below.

Post-review fixes (same release):
- pyproject version bumped from 0.3.18 → 0.3.19 (was missing).
- README: dead "qoa4ml_lib/qoa4ml/" link replaced with src/qoa4ml/reports/.
- docs/metrics.md: removed Network I/O row pointing at deleted system_report();
  eva_* output keys documented as DataQualityEnum string values; ts_inference_*
  return shapes (empty dict / Error envelope) made explicit.
- docs/index.md: KafkaConnector extra corrected to qoa4ml[kafka]; supported
  connector_class list narrowed to the two QoaClient.init_connector handles.
- system_monitoring_probe / process_monitoring_probe: memory unit labels
  corrected from "Gb"/"Mb" to "GB"/"MB" (CHANGELOG had only fixed gpu_utils).
- ProbeConfig: require_register and log_latency_flag now default to False
  (were unintentionally required, breaking shipped example configs).
- ProbeConfig.frequency description corrected: it is Hz, not seconds.
- MLReport / RoheReport: ReportTypeEnum.security is now a real branch with
  its own MlQualityReport.security stage dict; MLReport.combine_stage_report
  is pure (no longer mutates current_stage_report).
- node_aggregator.NodeAggregator.stop(): now stops the underlying
  SocketCollector before joining (previously hung on join() forever).
- node_aggregator.convert_unit / _process_hpc_report no longer mutate the
  caller's dict; HPC reports missing metadata/timestamp are dropped with
  a log line instead of KeyErroring.
- mlquality: numpy scalars/arrays coerced to Python types so downstream
  json.dumps / Pydantic serialization no longer blows up.
- qoa_client: registration_url POST now has a (5s, 30s) timeout, validates
  scheme (http/https only), and refuses link-local cloud-metadata addresses
  (SSRF/blast-radius reduction). asyn_report renamed to
  _send_report_via_connectors with backward-compat alias kept.
- PromConnector: unknown metric Type rejected at construction; inc/dec/observe
  raise ValueError on wrong type instead of silently no-oping; full type hints.
- amqp_collector / socket_collector: per-frame size cap (1 MiB default) so a
  hostile producer cannot OOM the consumer thread; payloads logged at DEBUG
  (not INFO) since they may carry user/instance identifiers.
- amqp_collector AMQP-vs-AMQPS detection switched from substring match to
  urlparse(...).scheme.
- kafka_connector: payload moved from INFO to DEBUG; INFO records size only.
- embedded_database.get_latest_timestamp: bounded fallback (exponential
  back-off up to 24h) replaces unbounded full-table scan.
- qoa_utils.get_cgroup_version: resolves `mount` via shutil.which (CWE-427
  hardening); subprocess.run with timeout replaces piped Popen.
- qoa_utils: open() helpers pass encoding="utf-8" explicitly; load_config
  removed unreachable ``return None``.
- rohe_ObService: missing/non-JSON POST body now returns HTTP 400 (was 200);
  Flask debug mode and bind host gated behind ROHE_OBS_DEBUG / ROHE_OBS_HOST
  env vars (default debug off, default bind 127.0.0.1) — closes RCE risk.
- Probe: removed dead ``execution_flag``, ``report_thread``, ``max_latency``;
  removed dead ``inference_flag`` / ``process_monitor_flag`` from QoaClient.
- Tests: 30+ new regressions in tests/test_regressions_0_3_19_post.py.

Additional breaking changes from post-review fixes:
- PromConnector.inc/dec/observe raise ValueError on type mismatch (were
  silently no-op'ing). Callers that depended on silent no-ops will break.
- PromConnector.__init__ raises ValueError on unknown ``Type``.
- registration_url with file://, ws://, or 169.254.169.254 will now raise.
- AMQP/socket collector: requests larger than 1 MiB are dropped with an error
  log instead of being processed.

Second-pass hardening (same release):
- rohe_ObService: identifier inputs (application_name, user_id, stage_id,
  instance_name) validated against ``^[A-Za-z0-9_-]{1,64}$`` so attacker
  input cannot inject AMQP routing-key wildcards (#/*) or Mongo path
  metacharacters; Mongo db_name now derived from the server-side UUID,
  not user input.
- rohe_ObService: optional bearer-token auth via ``ROHE_OBS_TOKEN`` env
  var (compared with ``hmac.compare_digest``, scheme case-insensitive per
  RFC 7235); module-level state guarded by ``threading.Lock``; bounded
  application registry (``_MAX_APPLICATIONS=1000``) returning HTTP 503.
- rohe_ObService: GET no longer reflects the raw query string, DELETE no
  longer echoes the request body; both return fixed payloads.
- rohe_ObService: per-application 1:1 ``application_id → agent`` invariant
  documented and pinned by a regression test; failed ``agent.start()``
  rolls back the bookkeeping entry instead of leaving an orphan
  "starting" record that used to brick the application_id forever.
- rohe_ObService: ``connector_config`` / ``collector_config`` / ``db_config``
  are now deep-copied per request; the previous shallow ``.copy()`` let
  concurrent registrations race on the shared inner ``conf`` dict.
- rohe_ObService: status updates after ``agent.start()`` re-read through
  ``agent_list`` rather than writing through a potentially-stale alias.
- ClientInfo: ``model_config = ConfigDict(validate_assignment=True)`` so
  ``QoaClient.set_config(field, bad_value)`` raises ``ValidationError``
  instead of silently storing an unchecked value.
- merge_report: rewritten to be pure (no longer mutates either argument)
  and no longer wraps the body in ``except Exception``; type signature
  widened to ``Any`` for parity with recursive scalar/dict cases.
- QoaClient.set_config: rejects unknown attribute names (was silent
  attribute injection on a non-frozen ClientInfo); raises AttributeError.

Fixes:
- QoaClient: config_dict / config_path precedence is now strict (elif);
  providing neither with no registration_url raises ValueError instead
  of AttributeError.
- node_aggregator: edge-environment path now parses incoming JSON into
  SystemReport / ProcessReport instead of relying on two permanently
  dead isinstance() branches.
- rohe_ObService: handler no longer NameErrors on non-JSON POSTs;
  agent status is recorded as "running" after start() (was "stop").
- Rohe_Agent.stop() now actually stops the AMQP collector (channel +
  connection close); previously only flipped an unused flag. Also
  fixed the 'colletor_conf' typo.
- DataConstraint default name typo: "data_constaint" -> "data_constraint".
- GPU memory unit label: "Gb" -> "MB" (value was MB but mislabeled).
- get_dict_at now raises IndexError on out-of-range instead of silently
  returning None.
- PromConnector.set() on a Counter now raises ValueError instead of
  silently incrementing.
- PromConnector.update_violation_count() replaced by
  render_violation_counts() which actually returns the rendered bytes.
- MQTT connector: swapped pub/sub queue assignments so they match the
  documented config semantics (in_queue is subscribe, out_queue publish).
- Probe + RepeatedTimer: wrap callback in try/except so a single bad
  tick cannot silently kill the monitoring thread.
- SocketCollector: added stop() and accept/client timeouts.
- SocketConnector: broadened catch to OSError; added send timeout.
- DockerMonitoringProbe: catches real Docker SDK exceptions
  (DockerException, RequestException, OSError).
- docker_util: guard against idle-sample zero-division and untagged
  images (image.tags[0] IndexError).
- MqttConnector: clean ImportError when paho-mqtt missing; added
  send_report() so the class is instantiable.
- KafkaConnector: use the correct confluent_kafka dict config.
- GeneralApplicationReport: implemented generate_report() (class was
  uninstantiable due to abstract method).
- embedded_database.get_latest_timestamp: UTC-aware datetimes + max()
  with a bounded lookback window.
- qoa_utils.CGROUP_VERSION: lazy via __getattr__ + @lru_cache; no more
  subprocess("mount") at import time.
- process_monitoring_probe / node_aggregator / exporter: removed
  module-level logging.basicConfig hijacks.
- dataquality_utils.image_quality: proper types, TypeError on bad input.

Dead-code removal:
- Deleted legacy example/bts/ tree (imports Qoa_Client, observeMetric,
  qoa4ml_lib — none of which exist in the current package).
- Deleted sys_monitor / system_report and their three never-True flags.
- Deleted commented-out OutlierDetector block (dataquality_utils.py).
- Deleted commented-out process_report/process_monitor block (qoa_utils.py).
- Deleted the dead "if require_register: self.obs_service_url = ..."
  assignments across process/system/docker probes.

Docs:
- Rewrote docs/index.md from scratch; previous copy referred to camelCase
  methods, a non-existent qoa4ml_lib path, a made-up report schema, and
  Metric/Counter/Gauge classes that do not exist.
- docs/metrics.md synchronized with real enum members and signatures.

Tests:
- 486+ tests, incl. new regressions for every fix above.

Breaking changes:
- DataQualityEnum.ACCURACY string value: "accuracy" -> "data_accuracy";
  MLModelQualityEnum.ACCURACY: "accuracy" -> "model_accuracy". This
  eliminates a silent Pydantic-coercion collision between the two.
- ClientInfo.custom_info is now strictly dict (was dict | str).
- mlquality return keys normalised to lowercase / PEP-8 (e.g. "MAE" ->
  "mae", "Training Loss" -> "loss", "Evaluate Accuracy" ->
  "val_accuracy", "Confidence" -> "confidence"). Consumers relying on
  the old capitalised keys must update.
- PromConnector.set() on a Counter raises instead of silently
  incrementing; PromConnector.update_violation_count() replaced by
  render_violation_counts().
- Rohe_Agent.stop() now performs a full shutdown (channel + connection).

Third-pass post-review fixes (same release):
High:
- kafka_collector.start_collecting now subscribes to the configured topic
  and dispatches each message to on_request (previously polled without
  subscribing → silently dropped all traffic). Consumer is closed on stop.
- mqtt_connector.on_connect now matches paho VERSION2 signature
  (client, userdata, flags, reason_code, properties); previous v1 arity
  raised TypeError on every connect, losing all subscriptions silently.
- general_application_report.observe_inference wraps non-list values so
  Pydantic doesn't ValidationError; process_previous_report guards the
  empty-metrics case against IndexError on metrics[-1].
- DataQualityEnum.NONE_RATIO now computes the actual none/NaN fraction
  (was returning the VALID fraction); dashboards relying on the label
  were plotting the inverse.
- get_process_allowed_memory: divides by number_of_tasks only when > 0
  (the task_* glob rarely matches on real cgroup layouts, and the old
  code raised ZeroDivisionError each probe tick).
- AmqpConnector: publishes serialized on a threading.Lock so concurrent
  QoaClient submits can't corrupt the pika BlockingConnection; retry
  failure now raises AmqpPublishError instead of silent drop.
- ClientConfig.validate_probe_type tolerates probe entries that arrive
  as already-instantiated ProbeConfig instances (previous .get() call
  raised AttributeError).

Medium:
- Probe.start_reporting stops any existing timer before creating a new
  one — no more leaked daemon thread on double-start; latency log path
  uses os.path.join instead of naive string concatenation.
- Rohe_Agent: Mongo insert wrapped in try/except PyMongoError; double
  start() guarded; mongo_client.close() in stop(); no more connection
  pool leak across restart cycles.
- rohe_ObService: startup raises SystemExit when config fails to load
  (previously crashed on first request); PUT/DELETE stubs return HTTP
  501 with a consistent auth gate instead of fake-success payloads.
- node_aggregator.convert_unit: unknown unit strings pass through
  unchanged rather than raising KeyError; metadata-prefixed keys are
  never unit-converted.
- MLReport / RoheReport: combine_stage_report deep-copies current
  stages so caller mutations to the returned report don't bleed back
  into self.report; observe_metric stores a deep copy of the caller's
  Metric so caller-side records.append() cannot mutate stored state.
- QoaClient gains a ``strict: bool = False`` kwarg; when True, connector
  init failures (or zero connectors) raise instead of silent degraded
  mode. Default False preserves legacy behaviour.
- init_probes: clearer error message for JetsonSystemProbeConfig /
  JetsonProcessesProbeConfig since those types are accepted by the
  config parser but not wired in init_probes yet.
- _is_link_local_metadata_host also blocks the common DNS names for
  cloud metadata services (metadata.google.internal, instance-data,
  etc.). Still narrow by design — does not block loopback/RFC1918.
- dataquality_utils: pandas and Pillow imports are now lazy via
  _require_pandas() / _require_pil(); module imports cleanly on core
  installs without the qoa4ml[ml] extra.

Low / docs:
- ml_report_model: mutable field defaults switched to
  ``Field(default_factory=...)``.
- gpu_utils: broader except (NVMLError, OSError, ImportError) so a
  missing NVML shared-library doesn't kill module import on non-GPU
  hosts.
- logger: handler attached only when no handlers exist (avoids
  duplicate lines under reload / double-import).
- amqp_connector: sub_properties moved from instance to local scope
  (was racy); AMQPS detection uses urlparse scheme instead of substring.
- docs/index.md: MLReport JSON example now shows the ``security: {}``
  key; PromConnector clarified as a metric registry (not a
  BaseConnector); MetricClassEnum value casing corrected; client.role
  note reconciled with ClientInfo Field; frequency doc notes integer
  Hz only.
- docs/metrics.md: classification_confidence row added.
- observability/qoa4mlopa/README.md: removed reference to a
  ``bim-runtimemetrics-ex1.json`` that does not ship with the repo.
- CHANGELOG regression-count line corrected.

0.3.18 (25/03/2026)
---------------------
Major refactor and production readiness release:
- Migrate from Rye to uv for package management
- Drop Python 3.9/3.10/3.11, target Python 3.12+
- Modernize all type hints to Python 3.12+ syntax
- Add mypy type checking to CI (0 errors)
- Replace pickle with JSON in socket connector/collector (security fix)
- Replace unmaintained flatten_dict and lazy-import with stdlib
- Add thread safety to QoaClient (all mutating methods locked)
- Add AMQP heartbeat keepalive and reconnect backoff
- Relax pydantic (<3) and docker (<8) version pins
- Fix critical bugs: pydantic v1 API, enum typos, missing returns
- Replace bare except Exception with specific types throughout
- Add comprehensive test suite (428 tests, all modules covered)
- Add Field descriptions to all config models for documentation
- Add metrics documentation, report and data quality examples
- Add CI workflows: lint, typecheck, test, publish (PyPI OIDC)
- Add Dependabot for automated dependency updates
- Remove outdated examples and legacy test directories
- Define public API in __init__.py, add py.typed (PEP 561)
